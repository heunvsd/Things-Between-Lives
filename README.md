# Things Between Lives

워크숍 참여자의 이야기와 같은 사물에 관한 온라인 기록을 함께 읽는 웹사이트입니다.

- **1**: 워크숍 원문과 6단 기록. 창 폭을 좁히면 회색 블록과 겹침, 연결 구절의 강조가 나타납니다.
- **2**: 영문 제품명 링크와 “이 물건을 선택하며 어떤 생활을 기대하나요?”라는 질문. 입력 후 Enter로 비교하며 Shift+Enter는 줄바꿈입니다. 관련 없는 구절에는 둥근 검정 취소선, 닮은 구절에는 같은 색과 원문 링크가 표시됩니다.
- 김항욱·이해인의 기록을 표시합니다. 다른 14명의 데이터와 이름은 보존하고 본문만 숨겼습니다.

## 실행

빌드나 API 키가 필요 없는 정적 사이트입니다. 저장소 폴더에서:

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

`http://127.0.0.1:8766/`를 엽니다. `index.html`과 `index-ink.html`은 같은 최신 화면입니다. `file://`로 열면 의미 비교 워커가 동작하지 않습니다.

## 의미 비교

Transformers.js와 다국어 MiniLM q8을 브라우저 워커에서 실행합니다. 입력 내용은 서버나 API로 전송하거나 영구 저장하지 않습니다. 새로고침하면 지워집니다.

GitHub의 파일 크기 제한 때문에 약 118 MB의 ONNX 가중치는 저장소에서 제외했습니다. 첫 비교 때 공식 [Hugging Face 모델 저장소](https://huggingface.co/Xenova/paraphrase-multilingual-MiniLM-L12-v2)에서 내려받고 브라우저에 캐시합니다. 로컬 모델이 `assets/semantic/models/`에 있으면 그것을 우선 사용합니다. 처음에는 네트워크 연결과 다운로드 시간이 필요합니다. 런타임·토크나이저·라이선스는 포함되어 있습니다.

검토한 11개 기대·경험 묶음과 보수적으로 비교하며, 모든 뉘앙스를 판단하지는 않습니다. 공통점이 불확실하면 연결하지 않습니다. 자세한 구조와 범위는 [README-ink.md](README-ink.md)를 참고하세요.

## 정적 호스팅

저장소 루트를 정적 사이트로 서비스하면 됩니다. GitHub Pages를 사용할 경우 `main` 브랜치의 `/ (root)`를 소스로 설정합니다. 모든 내부 자산 경로는 상대 경로입니다.

## 서체

본문은 기존 Noto Serif KR·조선굴림·Adobe Fonts의 Joly Text, 하단 이름은 Resist Sans Display를 유지합니다. Adobe 웹폰트는 기존 웹 프로젝트 CSS를 사용합니다.

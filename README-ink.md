### 의미 비교와 범위

`semantic-worker.mjs`가 Transformers.js 3.8.1과 다국어 MiniLM q8을 Web Worker에서 실행합니다. 런타임과 토크나이저는 `assets/semantic/`에서 읽습니다. 모델 가중치가 로컬에 있으면 재사용하고, 없으면 공식 Hugging Face 모델 저장소에서 내려받습니다. GitHub의 단일 파일 크기 제한 때문에 약 118 MB의 ONNX 가중치는 Git에 포함하지 않습니다. 입력을 서버/API에 보내지 않으며 키가 필요하지 않습니다. 최초 비교 때 약 151 MiB의 모델/런타임 자산을 준비하므로, 배포 시에는 자산 캐시를 권장합니다. 이후 비교는 워커와 모델을 재사용합니다. 웹 서버(HTTP/HTTPS)로 열어야 하며 `file://`에서는 사용할 수 없습니다.

상단 원문은 2에서 보이지 않는 동일 높이 기준으로 남기고, 하단 본문은 두 모드 모두 같은 인라인 구조에서 텍스트 노드만 장식합니다. 따라서 모드/비교 전후 글자 폭, 줄바꿈, 글 상자 좌표가 유지됩니다. 입력 전에도 2의 6단은 보이며, 제출한 비교 결과가 생기면 취소선이 적용됩니다. 취소선은 검정 가운데 면과 원형 양끝을 합성해 표시하고, 텍스트 너비나 줄바꿈을 바꾸지 않습니다.

자유 입력을 문장/절 단위로 임베딩해, 동일 사물의 기록에서 검토한 **11개 기대·경험 묶음**과 비교합니다. 현재는 휴식·환기·취향/인상·칭찬·자기 선물·향의 기억(향수), 기분 전환·좋아하는 향·새로운 향·간편한 휴대·보습(립밤)의 범위입니다. 단어 포함 검사나 생성된 인용문을 쓰지 않습니다. 반대 지향 예시와의 차이, 최소 유사도, 후보 간 차이가 부족하면 연결을 만들지 않습니다. 문장 모델은 논리/부정/복합 의도를 완벽히 판별하지 못하고, 검토된 범위 밖의 유사성은 놓칠 수 있습니다. 범위를 넓히려면 실제 기록을 확인하고 묶음과 인용 구간을 추가해야 합니다.

- `semantic-themes.json`: 검토된 구절의 출처 ID·섹션·문자 범위와 의미 벡터. 본문은 원본 파일에서 그대로 읽습니다.
- `semantic-matcher.mjs`: 유사도/반대 의미/모호성 판정과 입력 구간 분리.
- `visitor.js`: 입력, 모드, 사람별 결과, 로딩·취소·오류 UI.

## 기존 워크숍 화면

- 현재는 김항욱(13)·이해인(14)의 본문만 표시합니다. 하단 이름 16개는 유지하며, 다른 이름을 선택하면 본문 영역이 비어 있습니다. 원문·번역·연결 데이터와 렌더링 코드는 삭제하지 않았습니다. app-ink.js 맨 위의 visibleParticipantIds에 번호를 추가하면 다시 표시되고, new Set(participants.map(person=>person.id))로 바꾸면 전원이 복원됩니다.
- 워크숍 참여자 16명의 원문은 한글만 표시합니다. 관련 기록 132개는 원문 제목·출처를 검토해 한국어 기록 22개는 한글만, 해외 기록 110개는 영어 번역만 표시합니다. 본문과 상세 보기 모두 같은 기준이며, 작성자 고유 이름은 보존합니다. 국적을 알 수 없는 필명은 원문 언어를 기준으로 분류했습니다. 표시 기준과 영문 작성자 설명은 account-languages.js에 있으며 원문·번역 데이터는 삭제하지 않습니다.
- 브라우저 창을 좁히면 관련 기록에 반투명 회색 블록이 나타납니다. 가려진 글은 옅게 비치고, 연결 구절은 선명한 이탤릭으로 남습니다. 넓히면 정자와 전체 문장이 복원됩니다.
- 항욱님 화면에서 첫 블록이 나타나면 원문의 연결 묶음 순서대로, 원문 단어와 아래의 해당 이탤릭 구절들이 함께 붉은색(#c9002b)으로 바뀝니다. 최초 200ms 후 시작하고 묶음 사이 간격은 850ms이며, 색은 점진적으로 섞이지 않고 즉시 전환됩니다. 180ms 뒤 아래 구절의 밑줄이 240ms 동안 그어집니다. 레퍼런스 이미지의 Display P3 색을 sRGB로 변환해 추출한 붉은색입니다. 창을 줄이는 도중 줄바꿈이 바뀌어도 같은 시간축을 이어가며, 완전히 넓히거나 참여자를 바꾸면 초기화됩니다.
- 아래 이탤릭 구절은 해당 작성자의 시트 원문 URL로 연결되며 새 탭으로 열립니다. 원문 URL과 각 구절의 출처 ID를 직접 연결했고, 여러 줄의 한 구절은 키보드 탐색에서 한 번만 정지합니다. 위 워크숍 원문은 정자를 유지하고, 연결되지 않은 문장과 다른 참여자의 강조 방식은 유지합니다.

- 블록의 윗변은 기존 위치를 유지하되 아랫변은 각 글줄의 실제 폰트 영역 하단보다 0.5px 아래까지 확장합니다. g·y·p·q·j의 디센더가 블록 아래로 빠져나오지 않게 하며, 행간·글자 크기·반투명도는 바꾸지 않습니다.
